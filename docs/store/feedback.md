# Обратная связь: баги и идеи

Готовые тексты для обсуждений на странице VK Play и GitHub Issues: правила, шаблон
баг-репорта, шаблон идеи, закреплённый пост. Вставляются как есть.

**Что изменилось после itch.io.** Доски Community у itch были единственным каналом,
но itch.io недоступен из России (см. [vk-play-page.md](vk-play-page.md), § вступление),
а значит и доски вместе с ним. Основным каналом становится GitHub Issues — он
открывается из России, хранит историю и привязан к коду. Обсуждения на странице
VK Play, если площадка их даёт, работают как «входная дверь»: там отвечаем и
переводим воспроизводимые баги в Issue, чтобы они не терялись.

## 1. Закреплённый пост («Правила и как сообщить о проблеме»)

```
Здесь собираем баги и предложения по AnomalyPath 0.1 Alpha Demo.

Перед созданием темы:
1. Проверьте, нет ли уже такой темы — допишите в неё, если есть.
2. Одна тема = одна проблема. Не сваливайте пять багов в один пост.
3. Версия одна: 0.1. Если обновитесь — укажите новую версию.

Как сообщить о баге — по шаблону ниже (скопируйте и заполните).
Чем точнее шаги воспроизведения, тем быстрее починим.

Что приложить:
— скриншот или короткое видео;
— лог игры: %USERPROFILE%\AppData\LocalLow\VlomInc\AnomalyPath\Player.log
  (архивом или ссылкой, не вставляйте тысячи строк текстом);
— сохранение, если баг воспроизводится только в нём:
  %USERPROFILE%\AppData\LocalLow\VlomInc\AnomalyPath\Saves

Чего здесь не будет: спойлеров в заголовках — сюжетные повороты прячьте под
предупреждение. Токсичность, политика и оффтоп удаляются.
```

## 2. Шаблон баг-репорта

```
Заголовок: [0.1] Кратко: что и где

Версия игры: 0.1
Windows: (например, Windows 11 24H2, x64)
Разрешение окна / монитора: (например, 1920×1080 / 2560×1440)
Что делал (шаги):
1.
2.
3.

Ожидал:

Получилось:

Как часто повторяется: всегда / иногда / один раз
Когда началось: (новая игра / после загрузки сейва / после обновления)

Лог: Player.log архивом
Сейв: приложен / не нужен
Скриншот или видео:
```

Пример заполненного заголовка: `[0.1] Инвентарь: предмет не перетаскивается в быстрый слот`.
Такой формат позволяет сортировать темы по экрану и не читать каждую целиком.

## 3. Шаблон идеи

```
Заголовок: [Идея] Кратко: что добавить

Что предлагаю:

Зачем это игроку:

Как это вписывается в текущую петлю (хаб → маршрут → бой → возврат):

Готов ли помочь: тест / текст / арт / ничего
```

Идеи не обещаем: в ответ писать «записал», а решение фиксировать в
`docs/ROADMAP.md` — иначе предложения теряются между версиями.

## 4. Как отвечать

- Закрытый баг — сообщением «починено в 0.1.x» и, если возможно, ссылкой на коммит.
- Повтор — закрыть со ссылкой на исходную тему.
- Не удалять критику. Удалять только спам, рекламу и токсичность.
- Вложения — файлом к сообщению или ссылкой на GitHub; внешние файлообменники
  не требуем и не обещаем их сохранность.
- Воспроизводимые баги из обсуждений переносить в Issues, оставляя в теме ссылку:
  там есть метки, поиск и связь с кодом.

## 5. Каналы

| Канал | Для чего | Ограничение |
| --- | --- | --- |
| [GitHub Issues](https://github.com/akarpov2k/AnomalyPathGame/issues) | основной: баги, идеи, история решений | нужен аккаунт GitHub |
| Обсуждения на странице VK Play | быстрый вход для игроков без GitHub | нет поиска и связи с кодом |
| Комментарии к релизу на GitHub | разовые вопросы после выхода версии | не для отчётов с логами |

Дублировать баг в двух местах не нужно: достаточно одного, ссылку можно дать в ответе.
