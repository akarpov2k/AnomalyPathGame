# Карточка AnomalyPath на VK Play

Готовые тексты и порядок заполнения карточки игры. Всё, что делается в браузере,
делается вручную: VK Play не публикует сборки из командной строки.

**Почему не itch.io.** itch.io недоступен из России — магазин заблокирован в сентябре
2025 ([запись itch.io](https://itch.io/blog/1031968/itch-now-banned-in-russia),
[ixbt](https://ixbt.games/news/2025/09/13/roskomnadzor-zablokiroval-platformu-indi-igr-itchio-v-rossii.amp.html)).
Страница, которую нельзя открыть без обхода блокировки, не годится основной витриной:
её не увидят ни игроки, ни поисковики. VK Play работает из России и даёт каталог и
лаунчер, поэтому витрина — там, а файл по-прежнему доступен прямым релизом на GitHub.

## 1. Что нужно до заполнения

1. **Аккаунт разработчика.** Вход в кабинет VK Play — через VK ID; регистрация и
   привязка проекта описаны в пошаговом руководстве
   ([регистрация](https://documentation.vkplay.ru/hotbox/devdocs/pdfcopy/en/1098.pdf),
   [соглашение с разработчиком](https://documentation.vkplay.ru/hotbox/devdocs/pdfcopy/ru/1182.pdf)).
   Соглашение — юридический документ: читать целиком, а не по диагонали.
2. **Сборка для загрузки.** `Builds\AnomalyPath-Setup.exe` — 241,1 МБ
   (`sha256 4969E3EC2376AAA8F21C9FA7D17180594109CFB0A23B954C9737A728A92C2D24`);
   зеркало — `Builds\AnomalyPath-Windows.zip`, 237,5 МБ. В git их нет (`Builds/`
   в `.gitignore`), поэтому заливать нужно с локальной машины. Предел размера файла
   и допустимые форматы (инсталлятор или архив) сверить в инструкции кабинета:
   у площадок это меняется без предупреждения.
3. **Скриншоты.** `docs/screenshots/menu.jpg`, `walk.jpg`, `interior.jpg`,
   `setup.jpg` — кадры уже сделаны; нужен ещё кадр боя, его проще взять из игры.
4. **Возрастной рейтинг.** В данных игры маркировки нет. Предложение — **16+**:
   постапокалипсис, стрельба, кровь, смерть персонажа. Окончательное значение — по
   правилам площадки; оно же должно быть видно на странице и в игре.
5. **Реквизиты страницы:** ссылка на репозиторий
   `https://github.com/akarpov2k/AnomalyPathGame`, ссылка на донаты (Boosty) —
   отдельным полем, не вместо скачивания.

## 2. Поля карточки

Точные названия полей зависят от текущей версии кабинета — сверять с
[настройками карточки](https://documentation.vkplay.ru/hotbox/devdocs/pdfcopy/en/1101.pdf)
и [страницей игры](https://documentation.vkplay.ru/hotbox/devdocs/pdfcopy/ru/1047.pdf).

| Поле | Значение |
| --- | --- |
| Название | `AnomalyPath — Аномальное путешествие` |
| Тип | игра, отдельная (single-player) |
| Жанр | RPG; второй вариант — приключение |
| Платформа | Windows (x64) |
| Цена | бесплатно (без покупок и без донатов через площадку) |
| Статус | в разработке / ранний доступ, версия `0.1 Alpha Demo` |
| Язык интерфейса | русский |
| Возрастной рейтинг | 16+ (подтвердить по правилам площадки) |
| Обложка и скриншоты | из `docs/screenshots/`, размеры — по инструкции кабинета |
| Сборка | `AnomalyPath-Setup.exe` (241,1 МБ) |
| Ссылки | репозиторий GitHub, донаты Boosty, план работ (`docs/ROADMAP.md`) |

Перед загрузкой карточка проходит ревью
([описание процесса](https://documentation.vkplay.ru/hotbox/devdocs/pdfcopy/en/1371.pdf)):
описание, скриншоты и сборка должны совпадать — расхождение возвращает карточку
на доработку.

## 3. Короткое описание

```
2D-постапокалипсис: вылазки в аномальные зоны, пошаговый бой и выживание на грани.
```

## 4. Описание страницы

Вставлять как текст; оформление (заголовки, жирный) набирать средствами редактора
карточки — разметку он может не разбирать.

```
AnomalyPath — 2D-игра про вылазки в аномальные зоны. Вместо 3D — экран, рисованные локации и кнопочное управление, вместо шутера — пошаговый бой. Жанровый ориентир — S.T.A.L.K.E.R., но в формате пошаговой RPG-вылазки.

Вы — сталкер, который живёт в хабе: берёт объявления с доски, снаряжается у торговцев, ремонтирует вещи и уходит на маршрут. Маршрут — сеть звеньев от хаба, поэтому вылазка каждый раз разная: лут и тайники, аномалии, NPC, противники и драка за артефакт.

Игровая петля:
хаб → подготовка → маршрут → лут и бой → возврат → продажа и квесты → следующий тир

Что уже играется в версии 0.1:
— маршрут-сеть: подтипы звеньев, ветки, содержание звена, возврат в хаб только через конец пути, генерация по seed;
— хаб: доска объявлений с таймерами, два торговца с ассортиментом и запасом, ремонт, отдых, карта мира, Депо как хаб второго тира;
— вылазка: поход по дороге с прокруткой, объекты на пути — лут, тайники, аномалии, NPC, противники;
— бой: пошаговый, зоны попадания, патроны с пробитием, скиллы оружия, медицина, травмы, побег, смерть с потерей инвентаря;
— мини-игры: взлом тайника и поиск артефакта в аномальном поле;
— персонаж: инвентарь с сеткой и быстрыми слотами, снаряжение, артефакты, износ, таланты, левелинг, голод и жажда, ночной штраф меткости;
— первая глава сюжета с диалогами и цепочкой АТП, повторяемые и сюжетные квесты;
— сохранения: слоты, респавн после смерти, постоянная смерть — по настройкам новой игры.

Это 0.1 Alpha Demo: играбельная первая глава, а не финальный релиз. Тексты — на русском.

Скачать: установщик AnomalyPath-Setup.exe (~241 МБ). Ставится в профиль пользователя, ярлык на рабочем столе и в «Пуск», удаление — через «Установка и удаление программ».

Сохранения: %USERPROFILE%\AppData\LocalLow\VlomInc\AnomalyPath\Saves
Лог игры: %USERPROFILE%\AppData\LocalLow\VlomInc\AnomalyPath\Player.log

Нашли баг или есть идея — пишите в Issues репозитория (или в обсуждения на странице), там шаблон отчёта.

Исходники и планы: https://github.com/akarpov2k/AnomalyPathGame
План работ: https://github.com/akarpov2k/AnomalyPathGame/blob/main/docs/ROADMAP.md
```

## 5. Системные требования

```
Windows 10/11, 64 бита
Видеокарта с поддержкой DirectX 11
ОЗУ: 4 ГБ
Место на диске: около 450 МБ после установки (установщик 241 МБ)
Разрешение: от 1280×720; рекомендуется 1920×1080 и выше
Интернет нужен только для скачивания
```

Требования ориентировочные, выведены из сборки (IL2CPP, URP 2D, .NET Standard 2.1);
отдельного рантайма .NET не требуется.

## 6. Управление

```
Мышь — все кнопки, перетаскивание предметов в инвентаре
W / D / ↑ / → — идти вперёд
S / A / ↓ / ← — назад
Shift — бег
Enter / E / F — взаимодействие с объектом на маршруте
I — инвентарь, C — персонаж, M — карта, J — квесты, T — таланты
F5 — быстрое сохранение, F9 — быстрая загрузка
Esc — назад / закрыть окно
```

Клавиши переназначаются в настройках игры. F8 — служебный переключатель режима,
в описание его не выносим.

## 8. Порядок публикации

1. Зарегистрировать аккаунт разработчика, принять соглашение.
2. Заполнить карточку по §2, вставить тексты из §3–§7.
3. Загрузить `Builds\AnomalyPath-Setup.exe`, указать версию `0.1`.
4. Отправить на ревью; после замечаний — править карточку, а не билд, если замечания
   про текст.
5. После одобрения — включить обсуждения и закрепить в них правила из
   [feedback.md](feedback.md).

## 9. После публикации

1. Добавить ссылку на карточку в `README.md` рядом со ссылкой на GitHub-релиз —
   отдельным коммитом, когда ссылка уже открывается.
2. Проверить страницу с телефона: длинное описание не должно разъезжаться.
3. Записать в `docs/PUBLISHING.md` дату публикации и номер версии карточки.
