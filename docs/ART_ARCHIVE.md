# Архив ассетов AnomalyPath

Назначение: перед заменой арта сохранить текущие используемые PNG так, чтобы любой из них
возвращался на место одной командой — без git, без потери GUID и без пересборки каталога спрайтов.

## Что лежит

```
art-archive/
├── art-<дата>-<commit>.zip        # сам архив
└── manifest-<дата>-<commit>.json  # манифест рядом (для быстрой сверки)
```

Внутри zip — `Assets/Art/...` (PNG и парные `.meta` в тех же путях) и `manifest.json`.

Снятые архивы:

| Архив | Что | PNG |
| --- | --- | --- |
| `art-2026-11-04-f418ba4.zip` | состояние коммита `f418ba4` (до арта нового стиля) | 156 |
| `art-2026-11-04-f418ba4-styleA-before-icons.zip` | перед заменой иконок предметов: stage-art локации + старые иконки | 165 |

Второй снят параметром `-Tag`: имя архива и манифеста получает хвост, поэтому снимок
на том же коммите не конфликтует с первым.

## Манифест

Шапка: `created`, `gitCommit`, `gitBranch`, `fileCount`, `totalBytes`.
Запись на файл: `path`, `meta`, `hasMeta`, `catalogId` (id в каталоге спрайтов, если папка
участвует в каталоге), `sha256`, `bytes`, `width`, `height`.

## Команды

```powershell
# снять архив текущего состояния
powershell -NoProfile -File tools\art-archive.ps1 -Action Snapshot

# повторный снимок на том же коммите: хвост имени (art-<дата>-<commit>-<Tag>.zip)
powershell -NoProfile -File tools\art-archive.ps1 -Action Snapshot -Tag styleA-before-icons

# сверить живые файлы с архивом (код возврата 1, если есть расхождения)
powershell -NoProfile -File tools\art-archive.ps1 -Action Verify

# вернуть отличающиеся и отсутствующие файлы вместе с .meta
powershell -NoProfile -File tools\art-archive.ps1 -Action Restore

# вернуть принудительно, включая файлы, изменённые после снятия архива
powershell -NoProfile -File tools\art-archive.ps1 -Action Restore -Force

# конкретный архив вместо самого свежего
powershell -NoProfile -File tools\art-archive.ps1 -Action Verify -Archive art-archive\art-2026-11-04-f418ba4.zip
```

Поведение, на которое можно рассчитывать:

- **Snapshot** не перезаписывает существующий архив: имя содержит дату и коммит, при совпадении
  скрипт останавливается, а не затирает прошлое состояние.
- **Verify** ничего не пишет и печатает, каких файлов нет и какие отличаются.
- **Restore** копирует PNG на прежний путь (GUID из `.meta` сохраняется), затем сам делает
  сверку и падает с кодом 1, если что-то не сошлось. Файл, изменённый после даты архива,
  по умолчанию пропускается — чтобы не затереть осознанную правку; `-Force` перезаписывает.

Проверено 2026-11-04: архив снят, `Verify` — 156 из 156; один файл намеренно испорчен →
`Verify` — 155 из 156 и код 1; `Restore` вернул файл, `Verify` снова 156 из 156,
`git status` по `Assets/Art` чистый (байты совпали с коммитом). Второй архив
с `-Tag styleA-before-icons`: 165 PNG, `Verify` — 165 из 165.

## Что защищено

`.meta` пакуется и возвращается рядом с PNG, поэтому ссылки префабов, сцены и каталога
не рвутся: перезапись идёт на тот же путь, а `SpriteCatalog.asset` собирается заново
из папок `Tools/AnomalyPath/Собрать каталог спрайтов`.

## Границы

- Архив покрывает только `Assets/Art/**/*.png`. `SpriteCatalog.asset`, префабы, сцена,
  `Assets/Data` и `generated/` в него не входят: каталог пересобирается инструментом,
  данные и префабы — в git, `generated/` — исходники, а не используемый арт.
- Восстановление не удаляет файлы, которых нет в манифесте.
- Папка `art-archive/` в git не добавлена; чтобы она не мусорила в `git status`,
  нужна строка `art-archive/` в `.gitignore` (агент этот файл без просьбы не правит).
