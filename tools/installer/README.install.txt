AnomalyPath — Аномальное путешествие
====================================

Запуск: AnomalyPath.exe (Unity Hub не нужен).
Вся игра и данные лежат рядом с exe; папку можно переносить целиком.

Управление:
- мышь — кнопки интерфейса;
- Esc — назад/закрыть окно или диалог (на игровой панели Esc ничего не делает).

Сохранения:
%USERPROFILE%\AppData\LocalLow\VlomInc\AnomalyPath\
Слоты сохраняются в JSON рядом с бэкапами .bak.

Удаление: Uninstall.exe в этой папке (или «Программы и компоненты»).
